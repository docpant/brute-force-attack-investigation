# Protocol Analysis

## DNS Activity

The browser initiated DNS requests to retrieve the IP addresses for:
- yummyrecipesforme.com
- greatrecipesforme.com

The DNS server responded with the associated IP addresses, allowing the browser to establish connections with the websites.

## HTTP Activity

HTTP requests were initiated after DNS resolution completed.

The browser:
- requested the webpage
- downloaded the malicious executable file
- connected to the malicious redirected website

## Security Observations

The network traffic confirmed:
- malicious file delivery
- unauthorized browser redirection
- communication with a malicious website

The protocol analysis supported the conclusion that the website had been compromised.
